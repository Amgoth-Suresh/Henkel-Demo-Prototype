# Technical Data Sheet Extractor

This is a small Streamlit application that extracts structured technical product information from PDF data sheets using either a Python/Regex method or Google Gemini. To run it, create and activate a Python 3.10+ virtual environment, install the dependencies with `pip install -r requirements.txt`, and start the app with `streamlit run app.py`; then select a sample or upload a PDF, choose an extraction mode, and click **Extract Information**. Python mode does not require an API key, while AI mode uses Gemini only and requires a Gemini API key from Google AI Studio; the default model is `gemini-3.8-flash`, and the model can also inspect page images to estimate graph values. The project contains fictional sample PDFs for demonstration, and extracted results can be downloaded as JSON or CSV. API keys are used only at runtime, and confidential documents should not be uploaded without authorization.
